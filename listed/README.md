# listed/

A `.pspdx` for each repository that has none of its own: the catalog vouches
for it, and its entry carries `listed_by`. Any file name ending in `.pspdx`;
the repository comes from `source`. Once the repository has its own `.pspdx`,
that file is used and the one here is redundant. Example:
[`pspdx-demo-abandoned.pspdx`](pspdx-demo-abandoned.pspdx).
